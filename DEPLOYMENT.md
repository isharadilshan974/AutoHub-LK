# AutoHub LK V4 Deployment Checklist

1. Create/choose Supabase project.
2. Run `supabase_schema.sql` in Supabase SQL Editor.
3. Register an AutoHub account.
4. Promote your admin email with the SQL command in README.
5. Put `SUPABASE_URL` and `SUPABASE_KEY` in Streamlit Secrets.
6. Push all V4 files to GitHub repo `isharadilshan974/AutoHub-LK`.
7. Confirm Streamlit entrypoint is `app.py`.
8. Wait for rebuild.
9. Test registration.
10. Test login.
11. Test seller vehicle upload.
12. Test admin approval.
13. Test buyer search.
14. Test favourites.
15. Test enquiry.
16. Test WhatsApp / Facebook share links.
